Digital signature

How the digital signature works

1

Fingerprint

The certificate's details become a unique fingerprint. Change one letter and it no longer matches.

2

Seal

The institution's private key seals that fingerprint. No other key can make the same seal.

3

Check

Anyone checks the seal with the institution's public key. It passes only if nothing changed.

Private key: kept secret

One per institution, stored encrypted, used only inside the signing service. Never shown or sent anywhere.

Public key: open to all

Published for anyone to check signatures with standard tools such as OpenSSL. No Certyfi software needed.

Think of it as a wax seal that cannot be copied, where everyone is given the pattern to check it against. Each institution has its own pair of keys, so one institution can never sign as another. The private key signs; the public key only checks. The signature is standard ECDSA P-256 (ES256), the same kind of cryptography that secures HTTPS websites. On any certificate's verification page, "Verify in this browser" runs the check on the viewer's own device, and the page also shows the fingerprint, the signature and the public key so an expert can repeat the check with their own tools. Each certificate records which key signed it, so an institution's key can be replaced in future without invalidating certificates it has already issued.
