Security

Protection built into every layer

ConcernHow Certyfi addresses it
Separation between institutionsEach institution's data is stored separately and checked on every request
Fraudulent issuanceMandatory two-person approval, including imported batches
Wrongful revocationSeparate page, typed confirmation and a second approver
Forged certificatesDigital signatures under each institution's own key
Tampering with historyAppend-only audit trail, anchored to Bitcoin
Key protectionA separate signing key per institution, encrypted at rest
Connected systemsHashed API keys with limited permissions, rate limits and signed webhooks
Personal dataKept off the audit chain, so it can be erased on request
Each control here is covered by automated tests, including attempts to cross between institutions, to approve one's own request, import or revocation. The Staff activity report checks the two-person rule across any period, for auditors.
