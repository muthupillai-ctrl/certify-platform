Built so far: institutions and roles, visual template designer, two-person issuance and revocation, signing, audit trail, Bitcoin anchoring, verification by QR code, printed code, paper number or file, dashboard, reports, paper import, the Partner API with instant updates, a student portal, email notifications and pay before issue.

Certyfi is still under development; the core is built and working, and the next step is testing with a first pilot institution. The 15 capabilities are the ones listed on the slide. Changes are checked on a separate test system before they reach production, which is now ready and empty for the first real institution. The tests run against a real database and cover separation between institutions, privilege escalation, approval and revocation rules, signing, the audit trail, anchoring, paper imports, reports, the Partner API and its webhooks, the student portal, payments and emails. Signatures and Bitcoin proofs were also checked with independent standard tools, and each new screen was exercised in a real browser.
