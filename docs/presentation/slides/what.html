What Certyfi is

One platform to design, issue, manage and verify

Two people for every certificate

One person prepares it and a different person approves it. The system blocks self-approval, even for administrators.

Proof that doesn't depend on us

Each certificate is signed with the institution's own key, using open international standards, and its history is timestamped on Bitcoin.

Many institutions, fully separate

Each institution has its own isolated workspace, users, branding and signing key.

These three properties define the product. Everything else in the deck supports one of them.
