Standard tools

Check a signature yourself

1

Copy three things

From the certificate's verification page: the public key, the signature and the fingerprint.

2

Run OpenSSL

Free, and included with macOS and Linux. No Certyfi software is involved.

3

Read the answer

"Verified OK" means genuine. Change one character and the check fails.

$ printf '%s' '5ca3a66a…f1ab16da' > fingerprint.txt

$ openssl base64 -d -A -in signature.txt -out signature.der

$ openssl dgst -sha256 -verify key.pem -signature signature.der fingerprint.txt

Verified OK

This is the "checkable with standard tools" promise in practice. On a certificate's verification page, the signature panel shows the fingerprint (what was signed), the signature and, under "Show public key", the institution's public key. Save the key as key.pem and the signature as signature.txt; the first command saves the fingerprint exactly (no line break at the end), the second turns the signature from text into the binary form OpenSSL reads, and the third checks it. We ran exactly these commands on a real certificate: "Verified OK"; with one character of the fingerprint changed, OpenSSL reported "Error Verifying Data". On Windows, OpenSSL comes with Git for Windows. Other ways to run the same check: the "Verify in this browser" button on the verification page uses the browser's own built-in cryptography; each institution's public keys are also published in the standard key-list format (JWKS) at /api/v1/verify/<institution>/jwks; and the downloadable digital credential is a standard signed JWT that any JWT library can check against those keys. Note: the fingerprint covers the certificate's key details, including the recipient's email, which is not shown publicly, so this check proves the institution's key signed that record and that it hasn't changed since.
